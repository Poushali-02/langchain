In this module, we cover the fundamental concepts of computer networks, including network topologies, network devices, and network protocols.

**Context:** Network Topologies

A network topology refers to the physical or logical arrangement of devices in a network. There are several types of network topologies, and each has its own advantages and disadvantages.

**Bus Topology:**

A bus topology is a type of network topology in which all devices are connected to a single cable, known as the backbone or bus. This cable serves as the central connection point for all devices in the network. Here's a brief overview of bus topology:

**Key Characteristics:**

1. **Single Cable**: Bus topology uses a single cable that serves as the backbone of the network.
2. **All Devices Connected**: All devices in the network are connected to the same cable, known as the bus.
3. **No Point-to-Point Connections**: Each device connects to the bus through a terminator or repeater, which prevents data collisions and ensures that data is transmitted correctly.
4. **Simple to Install**: Bus topology is relatively easy to install, as it only requires a single cable to be run through the network.

**Advantages:**

1. **Cost-Effective**: Bus topology is a cost-effective solution, as it only requires a single cable to be installed.
2. **Simple Installation**: Bus topology is easy to install, making it a great option for small networks.

**Disadvantages:**

1. **Difficult to Upgrade**: Upgrading a bus topology network can be challenging, as it requires replacing the entire cable.
2. **Single Point of Failure**: Bus topology is vulnerable to single points of failure, as a break or damage to the bus cable can bring the entire network down.
